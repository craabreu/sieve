Store dash-molecules; Study A, one repeat (seed 0); arms: element (incumbent) (55 runs), element + hybridization + aromatic (55 runs), element + num_ring_memberships (55 runs). Points are individual folds; the line is their mean and the bars are 95% confidence intervals from the Nadeau-Bengio corrected standard error with Student's t on k-1 degrees of freedom (Mach. Learn. 52:239, 2003), which accounts for the training molecules the 5 folds share -- they are not independent replicates. The dashed horizontal line in each panel marks the best value the other method reached for that metric. Dotted lines are the same metric on each fold's own training shards, scored unnormalized; where a panel shows one such line for several arms, those arms produce identical training numbers, since a training atom matches the class it was fitted into and so never backs off. The sweep also covered element (incumbent) 0; element + hybridization + aromatic 0; element + num_ring_memberships 0, not shown here.
